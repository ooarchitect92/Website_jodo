# Website_jodo

An independently implemented Jodo public-website recreation and owner-operated marketing/CMS platform, using Website Master Blueprint v1.3 (7 October 2026) as its implementation and acceptance reference.

## Delivery boundaries

This repository is under implementation. A source commit is not production sign-off. The final acceptance register distinguishes implemented, tested, blocked, and not-implemented work.

This is not Jodo's live payment or lending service. Official customer/institute login destinations remain external; this application must not collect Jodo credentials, payment secrets, or KYC documents. Reference branding, business claims and assets require owner approval before a public production launch. Third-party analytics, advertising and payment integrations are disabled until explicitly configured and verified.

Implementation, test evidence, startup instructions and the owner guide will be committed alongside the source.
